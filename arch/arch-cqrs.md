# Архитектура: CQRS

## :robot_face: Что такое CQRS / GoogleAI

CQRS (Command Query Responsibility Segregation) — архитектурный паттерн, разделяющий операции изменения данных (команды) и получения данных (запросы). Он позволяет использовать разные модели данных и независимые хранилища для чтения и записи, значительно улучшая масштабируемость и производительность сложных систем.

Команды (Commands): Отвечают за изменение состояния (создание, обновление, удаление). Содержат бизнес-логику и не возвращают данные.

Запросы (Queries): Отвечают исключительно за чтение данных. Они не меняют состояние системы и оптимизированы для быстрых выборок. Возможность рализации Event Sourcing.

Независимое масштабирование: Вы можете масштабировать сервисы чтения и записи отдельно в зависимости от нагрузки.

Оптимизированные хранилища: Можно использовать реляционную БД для команд (гарантия целостности данных) и NoSQL хранилище (например, Elasticsearch) для запросов.

Излишне использовать: В простых CRUD-приложениях или небольших проектах, так как паттерн значительно усложняет архитектуру и требует синхронизации между моделями.
